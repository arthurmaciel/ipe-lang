# SKY-L0115: tuple pattern not supported here yet

A tuple pattern was used in a position the compiler cannot lower yet.

Two tuple-pattern shapes are supported today, both *irrefutable* — they
always match, so the binding can never fail:

* a single-arm `case` that destructures a tuple, and
* a function parameter that is a tuple.

In both, every element must itself be irrefutable: a variable, a wildcard
`_`, or a nested tuple of those. A `case` on a tuple with more than one arm,
or a tuple whose element is a constructor or a literal (a *refutable*
element), is not supported yet.

## Tuple function parameter — works

Destructure the argument in the parameter list:

```sky
fst : (a, b) -> a
fst (a, b) = a

snd : (a, b) -> b
snd (a, b) = b
```

## Single-arm tuple `case` — works

One arm, variable / wildcard elements:

```sky
sum2 : Int
sum2 =
    case (1, 2) of
        (a, b) -> a + b
```

## Multiple arms / refutable elements — not yet

This matches a tuple with several arms (and a literal element), which needs
product-pattern exhaustiveness:

```sky
classify : (Int, Int) -> Int
classify pair =
    case pair of
        (0, b) -> b          -- literal element + extra arm: not yet
        (a, b) -> a + b
```

Bind the tuple irrefutably first, then branch on the parts:

```sky
classify : (Int, Int) -> Int
classify pair =
    case pair of
        (a, b) ->
            if a == 0 then b else a + b
```

`[feature: tuple-pattern-match]`

This is a current limitation of the Sky Rust compiler, not a problem with
your code. If richer tuple matching matters to your project, please tell us
at https://codeberg.org/sky-lang/sky-rust/issues.
