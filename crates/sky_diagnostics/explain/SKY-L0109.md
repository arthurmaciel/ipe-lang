# SKY-L0109: type parameters on a type alias not supported yet

Your `type alias` declares one or more type parameters — a lowercase
name like `a` or `value` after the alias name. Sky understands what you
mean, but this version supports only *non-parametric* aliases: an alias
must stand for one concrete type, with no parameters to fill in.

There's nothing wrong with the declaration itself; parametric aliases
are simply a feature Sky hasn't reached. Until it does, drop the
parameter and name the concrete type you actually need, or define a
separate alias per instantiation.

`[feature: parametric-aliases]`

A parametric alias hits this limit:

```sky
type alias Box a = a
```

So does an alias parametrised over a message type, a common UI shape:

```sky
type alias Producer msg = String -> msg
```

A non-parametric alias compiles — name the concrete type directly:

```sky
type alias Count = Int
```

This is a current limitation of the Sky Rust compiler, not a problem
with your code. If parametric type aliases are important to your
project, please tell us at
https://codeberg.org/sky-lang/sky-rust/issues.
