# SKY-I0011: intern: symbol table exhausted

Sorry about this one — the compiler ran out of room for names. Sky keeps an
internal table of every identifier it sees, and that table can hold up to
about four billion (`u32::MAX`) distinct entries. Filling it completely is
not something a normal program should ever do, so hitting this limit points
at a bug on our side rather than anything you wrote.

If your program is genuinely enormous this is still our problem to solve —
the compiler should grow its name table or report a friendlier limit long
before it gets here. Either way, this is an internal failure, not a mistake
in your code.

A perfectly normal program interns only a handful of names:

```sky
module Main exposing (main)

main : Task ()
main =
    Log.println "hello"
```

Even with many definitions, you stay far below the limit:

```sky
module Main exposing (main)

a : Int
a = 1

b : Int
b = 2

main : Task ()
main =
    Log.println (String.fromInt (a + b))
```

There's nothing to change in this code — it should compile comfortably:

```sky
module Main exposing (main)

total : Int
total = 100 + 7

main : Task ()
main =
    Log.println (String.fromInt total)
```

This is a bug in the Sky Rust compiler — not your fault. Please report it
(with this source + `skyc --version`) at

https://codeberg.org/sky-lang/sky-rust/issues

and tell us how large the program was so we can raise the ceiling sensibly.
