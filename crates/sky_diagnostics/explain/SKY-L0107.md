# SKY-L0107: first-class functions not supported yet

You referred to a function as a bare value, or you tried to call
something that isn't a plain kernel or top-level name — for example a
lambda used on its own, or a callee that is computed rather than named.
Sky can parse this, but it doesn't treat functions as values you can
pass around yet.

This is a feature still on the roadmap, not an error in your code. For
now, every call's callee must be a name the compiler already knows — a
kernel function or a top-level definition — and functions can't be
handed about as ordinary values.

`[feature: first-class-functions]`

Naming a function without calling it trips this:

```sky
chosen : Int -> Int
chosen =
    increment
```

So does calling the result of an expression rather than a name:

```sky
result : Int
result =
    (pickFn flag) 10
```

Call named functions directly with their arguments instead:

```sky
result : Int
result =
    increment 10
```

This is a current limitation, not a wrong move on your part. If passing
functions around matters for your work, please nudge us at
https://codeberg.org/sky-lang/sky-rust/issues.
