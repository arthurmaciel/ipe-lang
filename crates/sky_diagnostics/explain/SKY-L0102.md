# SKY-L0102: polymorphic type variables not supported yet

Your type annotation contains a type variable — a lowercase name like
`a` or `msg` that stands for "any type". Sky understands what you mean,
but this version is monomorphic: every annotation has to name concrete
types, so generic signatures can't be compiled yet.

There's nothing wrong with the annotation itself; polymorphism is simply
a feature Sky hasn't reached. Until it does, write the specific type you
actually need at each binding.

`[feature: polymorphism]`

A classic generic signature hits this limit:

```sky
identity : a -> a
identity x =
    x
```

So does any annotation that mentions a type variable, even nested:

```sky
firstOr : a -> List a -> a
firstOr fallback items =
    fallback
```

Pick a concrete type and the binding compiles:

```sky
identityInt : Int -> Int
identityInt x =
    x
```

This is a current limitation of the Sky Rust compiler, not a problem
with your code. If generic functions are important to your project,
please tell us at https://codeberg.org/sky-lang/sky-rust/issues.
