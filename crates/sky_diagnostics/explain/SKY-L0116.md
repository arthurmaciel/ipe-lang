# SKY-L0116: multiple `case` arms for the same constructor not supported yet

A `case` had two (or more) arms whose head is the *same* constructor — for
example, one arm for `Just (Just a)` and another for `Just Nothing`. This is
nested constructor *discrimination*: the two arms differ only in a refutable
sub-pattern of the same top-level constructor.

The Sky Rust compiler currently lowers a constructor `case` to a Rust `match`
with exactly **one arm per top-level constructor**. Ordered discrimination on
a refutable nested payload needs the multi-arm-per-constructor match
compilation that lands in a later milestone.

The exhaustiveness checker still runs first, so a *non-exhaustive* nested
`case` is reported as `SKY-T0010` with the missing pattern; an exhaustive one
that uses two arms for one constructor is gated here cleanly rather than
mis-lowered.

## Nested patterns that DO work

A nested constructor pattern is fine as long as each top-level constructor
appears in a single arm:

```sky
type Tree = Node Tree Int Tree | Leaf

label : Tree -> Int
label t =
    case t of
        Node _ x _ -> x
        Leaf -> 0
```

An irrefutable nested payload (a tuple or record) also works in one arm:

```sky
type Pair = Pair (Int, Int)

addPair : Pair -> Int
addPair p =
    case p of
        Pair (a, b) -> a + b
```

## The shape that is gated

Two arms for the same `Just` constructor:

```sky
flatten : Maybe (Maybe Int) -> Int
flatten m =
    case m of
        Just (Just a) -> a       -- arm 1 for `Just`
        Just Nothing -> 0        -- arm 2 for `Just`: not yet
        Nothing -> 0
```

## Rewrite — match the outer constructor once, then the inner

Pull the inner value out in a single `Just` arm and branch on it there:

```sky
flatten : Maybe (Maybe Int) -> Int
flatten m =
    case m of
        Just inner ->
            case inner of
                Just a -> a
                Nothing -> 0
        Nothing -> 0
```

`[feature: nested-ctor-discrimination]`

This is a current limitation of the Sky Rust compiler, not a problem with
your code. If nested constructor discrimination matters to your project,
please tell us at https://codeberg.org/sky-lang/sky-rust/issues.
