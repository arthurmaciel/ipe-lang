# Design specifications

Design specs for the compiler and runtime subsystems — the shape of each
subsystem, the invariants it upholds, and its implementation plan. These are
developer references, deeper than the decision records in [`../../adr/`](../../adr/)
(which capture *why* a choice was made) and complementary to them.

[`tbd/`](tbd/) holds specs for work that is proposed or in progress; the specs
at this level cover subsystems that are shipped or actively maturing.
