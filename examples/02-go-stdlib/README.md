# Go Stdlib

Demonstrates using Go standard library packages from Ipê, including `crypto/sha256`, `encoding/hex`, `time`, and `net/http`.

## Build & Run

```bash
ipe install
ipe build src/Main.ipe
./sky-out/app
```

Requires `ipe install` first to generate FFI bindings for Go stdlib packages.
