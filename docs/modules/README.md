# Module guides

A guide per stdlib module: the mental model, one worked and CI-verified example,
and the design rationale — the narrative home that the per-symbol `ipe doc`
reference points at. `ipe doc <Module>` remains the exhaustive per-symbol
reference; a guide never duplicates it.

- [`Ipe.Task`](Ipe.Task.md) — describe an effect as a value, then compose effects.
- [`Ipe.List`](Ipe.List.md) — transform, filter, fold, and order lists.
- [`Ipe.String`](Ipe.String.md) — build, slice, search, and parse text.

Add one as `docs/modules/<Module>.md`.
