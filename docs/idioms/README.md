# Idioms

Short, focused pages on how to express a recurring pattern well in Ipê — the
preferred shape for a common task, and why the language nudges you toward it.
Each idiom is one of the entry kinds `ipe doc` resolves.

Add one as `docs/idioms/<slug>.md` and it becomes discoverable through `ipe doc`.

- [`do`-notation](do-notation.md) — sequence two or more chained tasks.
- [The pipe: `|>`](pipe.md) — thread a value through several transformations.
- [Parse, don't validate](parse-dont-validate.md) — turn untyped input into a
  typed value once, at the boundary.
- [The Elm Architecture](tea.md) — structure a program that reacts to input over
  time.
