# IPE-P0069: duplicate type annotation for one name

A value name carries two or more `name : Type` annotations. A value can have
only one declared type, so a second annotation is ambiguous — the compiler
cannot know which one you meant. Rather than silently keep one and drop the
rest, it rejects the duplicate.

```ipe ipe:error
module Area exposing (area)

area : Int -> Int
area : Float -> Float
area n =
    n
```

Both `area : Int -> Int` and `area : Float -> Float` annotate the same
definition; there is no single type to attach.

## To fix

Keep the one annotation that states the type you want:

```ipe
module Area exposing (area)

area : Int -> Int
area n =
    n
```

If the two lines were meant for two different values, give each its own name
and definition:

```ipe
module Area exposing (areaInt)

areaInt : Int -> Int
areaInt n =
    n
```
