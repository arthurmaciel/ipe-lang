# IPE-L0118: `Live.appRouted` is not yet supported — use `Live.app` (non-routed) for now

You used `Live.appRouted`, the URL-routing variant of the Sky.Live
entry point. The Rust backend does not yet wire this variant — only
the non-routed `Live.app` (with `init`, `update`, `view`, and
`subscriptions`) is supported in this milestone.

`[feature: routed-live-app]`

Replace `Live.appRouted` with `Live.app` and remove the `routes` /
`notFound` fields from your cfg record until routing lands:

```sky
-- Not yet supported:
main =
    Live.appRouted
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ route "/" HomePage ]
        , notFound = NotFoundPage
        }
```

```sky
-- Supported now:
main =
    Live.app
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        }
```

```sky
-- You can still handle navigation manually inside update:
update msg model =
    case msg of
        Navigate path ->
            ( { model | page = parsePath path }, Cmd.none )
        _ ->
            ...
```

URL routing support (`Live.appRouted`) is tracked and will land in a
future milestone. If this blocks your work, please comment at
https://codeberg.org/sky-lang/sky-rust/issues.
