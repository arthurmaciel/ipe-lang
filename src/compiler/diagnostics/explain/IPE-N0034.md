# IPE-N0034: standard-library module used without importing it

You wrote a qualified name like `String.join`, and `String` really is one of my standard-library modules — but this file never imports it. Unlike some languages, I do not make every standard-library module ambiently available. Each file's `import` list is a complete inventory of the capabilities it reaches for, so a module you use qualified must first be imported.

Only a small, fixed vocabulary is available with no import: the operators and base types (`+`, `==`, `identity`, `Int`, `String`, …) and the core-language types `Maybe`, `Result`, `List` with their constructors. Everything else — `String`, `List`, `Dict`, `Http`, `Json.Decode`, and the rest — is used qualified and must be imported.

Here `String` is used with no import, so it does not resolve:

```ipe
shout : String -> String
shout text =
    String.toUpper text
```

Add the import the message names (`import Ipe.String`), and the qualified use resolves:

```ipe
import Ipe.String

shout : String -> String
shout text =
    String.toUpper text
```

The same rule holds for every standard-library module. Import each one you qualify against:

```ipe ipe:skip
import Ipe.Dict
import Ipe.List

tally : List String -> Dict String Int
tally words =
    List.foldl (\word acc -> Dict.update word bump acc) Dict.empty words
```

If instead the qualifier is genuinely unknown — a misspelling, or a module that does not exist — you will see IPE-N0004 rather than this error.
