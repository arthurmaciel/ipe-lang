# IPE-N0025: reserved namespace

A local module's name begins with `Sky` or `Std`, which are namespaces reserved for the Sky standard library and runtime. User modules must use a different first segment.

A module trying to claim a reserved namespace:

```sky
-- src/Sky/Extra.ipe
module Sky.Extra exposing (helper)
helper = "extended!"
```

This is rejected because `Sky` is reserved. Rename your module:

```sky
-- src/App/Extra.ipe
module App.Extra exposing (helper)
helper = "extended!"
```

The restriction applies to the first path segment only. `MyApp.Sky` or `Data.Std` are fine. Only modules whose first segment is exactly `Sky` or `Std` are rejected.

This rule exists to prevent local modules from silently shadowing stdlib modules. If a local `Std.Log` were allowed, every file that `import Std.Log` would import your local file instead of the stdlib logger, producing confusing type errors or silent misbehaviour.

Once the module is renamed, import it from your entry point as usual:

```sky
module Main exposing (main)
import App.Extra as Extra

main = println Extra.helper
```
