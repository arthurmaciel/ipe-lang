# IPE-T0011: redundant case branch

Your `case` expression has a branch that can never run. Two arms cover
the same constructor, so the second one is unreachable — the first arm
already catches every value that would have matched it. I'm flagging
it as a warning so you can decide what you actually meant.

This usually means one of two things: either the duplicate is a
copy-paste left over from editing and should be deleted, or one of the
two arms was supposed to match a *different* constructor and the name
is a typo. Either way, code that can't run is worth a second look.

Here `Red` is matched twice, and the second `Red` branch is dead:

```sky
type Colour
    = Red
    | Green
    | Blue

name : Colour -> String
name colour =
    case colour of
        Red ->
            "red"

        Red ->
            "scarlet"

        Green ->
            "green"

        Blue ->
            "blue"
```

If the duplicate was a mistake, remove it and keep the one branch you
want:

```sky
type Colour
    = Red
    | Green
    | Blue

name : Colour -> String
name colour =
    case colour of
        Red ->
            "red"

        Green ->
            "green"

        Blue ->
            "blue"
```

If the second arm was meant for a *different* constructor, give it the
right name so it covers the case you intended:

```sky
type Colour
    = Red
    | Green
    | Blue

name : Colour -> String
name colour =
    case colour of
        Red ->
            "red"

        Green ->
            "green"

        Blue ->
            "blue"
```
