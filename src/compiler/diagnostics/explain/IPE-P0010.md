# IPE-P0010: unknown character

I found a character in your file that isn't part of the Sky language. I
don't know how to read it as the start of anything — a name, a number,
an operator, or punctuation — so I stopped right at it.

This often slips in by accident: a "smart" quote (`“ ”`) pasted from a
document instead of a plain `"`, a non-breaking space that looks like a
normal space, a stray control character, or a symbol that simply isn't
used in Sky. Replace it with the ordinary character you meant.

Curly quotes are the classic culprit — they look right but aren't:

```sky
name =
    “Ada”
```

Use straight double quotes instead:

```sky
name =
    "Ada"
```

A symbol that has no meaning in Sky also lands here:

```sky
count =
    items § 2
```

Pick a real operator for what you intended:

```sky
count =
    items * 2
```
