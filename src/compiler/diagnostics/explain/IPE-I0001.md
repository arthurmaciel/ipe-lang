# IPE-I0001: internal compiler error

I'm not sure what went wrong here — sorry about that. The compiler hit a
state it didn't know how to handle and stopped before it could finish. This
is almost certainly a gap in the Ipe Rust compiler itself, not a mistake in
your code.

This is the generic catch-all for an internal failure that doesn't have a
more specific code yet. When you see it, the source you were compiling was
likely perfectly reasonable Ipe — the fault is on our side for not modelling
some shape correctly.

Even a tiny, ordinary-looking program can trip an internal error if it
exercises a corner the compiler mishandles:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A type-annotated definition feeding into the same path:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

There is nothing to "fix" in your code — this should just compile:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```

This is a bug in the Ipe Rust compiler — not a mistake in your code. Please
report it (with this source + `ipec --version`) at

https://github.com/arthurmaciel/ipe-lang/issues

and we'll get it fixed.
