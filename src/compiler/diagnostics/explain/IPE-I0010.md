# IPE-I0010: intern: unresolved symbol

Sorry — something went wrong inside the compiler. While turning your program
into its internal form, Sky assigns every name a small numeric handle (an
"interned symbol") and later looks the original name back up. That lookup
failed: a handle pointed at a name the compiler could no longer find.

This is a bug in the Sky Rust compiler, not a mistake in your code. A symbol
that was handed out should always resolve back to the text it stood for, so
reaching this state means an internal table got out of step with itself.

The kind of ordinary program that flows through this machinery:

```sky
module Main exposing (main)

name : String
name = "Sky"

main : Task ()
main =
    Log.println name
```

Several names being interned and resolved together:

```sky
module Main exposing (main)

first : String
first = "hello"

second : String
second = "world"

main : Task ()
main =
    Log.println first
```

Your code is fine — this should just resolve every name and compile:

```sky
module Main exposing (main)

main : Task ()
main =
    Log.println (String.fromInt 42)
```

This is a bug in the Sky Rust compiler — not your fault. Please report it
(with this source + `skyc --version`) at

https://codeberg.org/sky-lang/sky-rust/issues

so we can track down the stale handle.
