# IPE-E0001: could not reach the crate registry

The compiler finished translating your Ipe program to Rust, but when it went
to build the resulting crate, `cargo` could not contact the crate registry
(`crates.io`). This is a network or DNS problem on your machine — not a
mistake in your code, and not a bug in the compiler.

Common causes:

- You are offline, or your network connection dropped mid-build.
- A corporate firewall or proxy blocks outbound HTTPS to `crates.io`.
- DNS resolution is failing for `index.crates.io` or `static.crates.io`.

What to try:

1. **Check your connection.** Open a browser and confirm `crates.io` is reachable.
2. **Retry.** If the outage is transient, rebuild once you are back online.
3. **Use a local registry mirror.** If your environment blocks the default
   registry, configure a Cargo mirror in `~/.cargo/config.toml`:

```ipe
-- This is a Cargo.toml snippet, not Ipe source.
-- See cargo documentation for full mirror setup details.
```

4. **Work offline with a pre-populated cache.** Run `cargo fetch` while online
   to populate `~/.cargo/registry`, then rebuild.

Your Ipe program has nothing to fix — here is a valid program that would have
compiled fine if the registry were reachable:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A type-annotated variant also compiles fine:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

There is nothing to "fix" in your source — just restore network access and
try again:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
