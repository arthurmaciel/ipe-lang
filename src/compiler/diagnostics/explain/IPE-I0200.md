# IPE-I0200: ICE: no Rust name for symbol

Sorry — the compiler couldn't finish generating code for your program. When
Sky emits Rust, every type and function it kept needs a corresponding Rust
name. The backend asked for the Rust name of a symbol and got nothing back,
so it couldn't write out the code.

This is a bug in the Sky Rust compiler, not a mistake in your code. Every
symbol that survives to code generation should have a name reserved for it;
finding one without a name means the backend's bookkeeping got out of step.

A small program that the backend turns into Rust:

```sky
module Main exposing (main)

main : Task ()
main =
    Log.println "hello"
```

A user-defined type and function, both of which need Rust names:

```sky
module Main exposing (main)

type Light
    = Red
    | Green

describe : Light -> String
describe light =
    case light of
        Red -> "stop"
        Green -> "go"

main : Task ()
main =
    Log.println (describe Red)
```

This is ordinary Sky and should generate code without trouble:

```sky
module Main exposing (main)

double : Int -> Int
double n = n + n

main : Task ()
main =
    Log.println (String.fromInt (double 21))
```

This is a bug in the Sky Rust compiler — not your fault. Please report it
(with this source + `skyc --version`) at

https://codeberg.org/sky-lang/sky-rust/issues

so we can fix the backend's name table.
