# IPE-I0203: ICE: golden anchor missing

Sorry about this — the backend went looking for a fixed marker (a "golden
anchor") in the runtime template it ships with, and couldn't find it. These
anchors are landmarks the compiler relies on to splice your generated code
into the surrounding scaffold. A missing one means the embedded template and
the compiler that expects it have drifted apart.

This is a bug in the Ipe Rust compiler, not a mistake in your code. Nothing
you wrote can cause or prevent this — it's entirely about the compiler's own
internal template, which should always contain the anchors it searches for.

Any program at all routes through this template — even the smallest:

```ipe
module Main exposing (main)

main : Task ()
main =
    Io.println "hello"
```

A program that emits a user function still relies on the same anchors:

```ipe
module Main exposing (main)

shout : String -> String
shout msg = msg

main : Task ()
main =
    Io.println (shout "hi")
```

There is nothing to change here — this should build once the template is
intact again:

```ipe
module Main exposing (main)

main : Task ()
main =
    Io.println (String.fromInt 7)
```

This is a bug in the Ipe Rust compiler — not your fault. Please report it
(with this source + `ipec --version`) at

https://github.com/arthurmaciel/ipe-lang/issues

and we'll re-sync the embedded template.
