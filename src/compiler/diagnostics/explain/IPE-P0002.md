# IPE-P0002: unexpected end of file

I reached the end of your file while I was still in the middle of
reading something. Part of the code started but never finished, so
there was nothing left for me to read when I needed more.

This almost always means a closing piece is missing: an open `(`, `[`,
or `{` with no partner, a definition whose right-hand side trails off,
or an `if` / `case` / `let` that announced more was coming and then the
file simply ended. The fix is to complete whatever was left open.

For instance, a definition that promises a value but stops:

```ipe ipe:error
greeting =
```

Finish it with the value it should produce:

```ipe
greeting =
    "hello"
```

An opened parenthesis that never closes runs all the way to the end of
the file before I notice:

```ipe ipe:error
area =
    (width * height
```

Close it, and the expression is whole again:

```ipe ipe:skip
area =
    (width * height)
```
