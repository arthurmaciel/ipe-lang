# IPE-L0133: a CustomElement boundary value is not emittable yet (typed transport not shipped)

`CustomElement` names the typed boundary between an Ipê app and a
JavaScript-backed visual widget. A binding typed `CustomElement down up` is now
**accepted by the type checker**: the two parameters are checked to be plain,
closed value types (the seal), and the annotation type-resolves.

```ipe
editor : CustomElement Int String
```

What is not built yet is the **transport** — the machinery that actually places
the widget on the page: the generated JavaScript glue, the unique custom-element
tag name, and the page-update node that carries the widget's state. Until that
ships, a program that *builds* a `CustomElement` value cannot be compiled all the
way to a running program:

```ipe
editor : CustomElement Int String
editor = editor
```

The compiler stops here, cleanly, rather than producing a broken program. This
is a deliberate safety rule: no boundary value ever reaches code generation
without its typed transport in place, so a half-built widget can never slip
through and cross the seam untyped.

## How to fix

Until the `CustomElement` transport ships, reach a browser widget you already
have through the shipped, typed surface instead — an ordinary element and a
typed event handler in your `view`:

```ipe ipe:skip
view model =
    Ui.layout [] (Ui.text "a typed view, no untyped widget boundary")
```

When the transport lands, a `CustomElement` binding becomes buildable and the
compiler generates the encode/decode glue for its two parameters automatically.

## Glossary

- **transport** — the mechanism that carries a boundary value across the
  Ipê↔JavaScript seam. The typed contract (`CustomElement down up`) is fixed;
  the transport is the code that realises it on the page.
- **fail closed** — when something is not yet safe or not yet possible, refuse it
  rather than guess. Here: refuse to emit a widget whose transport is not built.
- **seam** — the boundary line between Ipê and JavaScript, where every crossing
  value is encoded or decoded.
