# IPE-L0153: Ui.cells is terminal-screen-only and not available in the Cli shape

`Ui.cells` paints a **raw character grid** onto the terminal. It is a
full-screen terminal primitive — it writes cell-by-cell into the alternate
screen that `Terminal.appScreen` renders.

A **Cli** app (`Terminal.appLines`) works differently: its `view` returns a
`String` that is printed as a line on stdout. There is no alternate screen, no
cell grid, and no character-cell surface to paint on, so `Ui.cells` has no
denotation there.

```ipe ipe:error
-- rejected: `Ui.cells` under `Terminal.appLines` (no cell grid in a Cli view)
module Main exposing (main)

import Ipe.Tea.Terminal as Terminal
import Ipe.Ui as Ui

view : Model -> String
view model =
    Ui.cells [ [ 'h', 'i' ] ]   -- type error: returns Element, not String

main =
    Terminal.appLines
        { init = init, update = update, view = view
        , subscriptions = subs, onLine = onLine
        }
```

## How to fix

**If you want a full-screen cell-grid app**, switch to `Terminal.appScreen`.
Its `view` returns an `Element` and can contain `Ui.cells` islands:

```ipe
-- accepted: `Ui.cells` inside a `Terminal.appScreen` view
module Main exposing (main)

import Ipe.Tea.Terminal as Terminal
import Ipe.Ui as Ui exposing (Element)

view : Model -> Element Msg
view model =
    Ui.column []
        [ Ui.text "board:"
        , Ui.cells model.grid
        ]

main =
    Terminal.appScreen
        { init = init, update = update, view = view
        , subscriptions = subs, onKey = onKey
        }
```

**If you want line output**, format the content as a `String` instead:

```ipe
view : Model -> String
view model =
    String.join "\n" (List.map String.fromList model.grid)
```

## Why this is an error

`Terminal.appLines` is the **Cli** shape — it is line-oriented I/O, not a
full-screen TUI. Allowing `Ui.cells` there would silently produce Rust that
type-mismatches (`Element msg` where `String` is required) and fails `cargo
build` after `ipe build` already reported success. The gate converts that into a
clean compile-time diagnostic so you know exactly what to change.
