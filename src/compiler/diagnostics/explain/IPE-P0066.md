# IPE-P0066: doc-string on a non-exported binding is unreachable

**This is a warning, not an error — the program still compiles and runs.**

A `{-| … -}` doc-comment was placed above a binding that is not listed in the
module's `exposing (…)` clause. Doc-tooling can only surface documentation for
symbols that callers can actually see; a doc-string on a private binding is
invisible to any downstream reader.

```ipe ipe:error
module Counter exposing (increment)

{-| Add one to the counter. -}
increment : Int -> Int
increment n =
    n + step

{-| The step size — documentation here is unreachable because `step` is private. -}
step : Int
step =
    1
```

The warning points to the `{-| … -}` above `step`. Because `step` is not in the
`exposing` list, its doc-string will never appear in generated documentation.

## To fix

Either remove the doc-string from the private binding:

```ipe
-- Internal step size (no doc-string needed; callers cannot see it).
step : Int
step =
    1
```

Or export the binding so the doc-string becomes reachable:

```ipe
module Counter exposing (increment, step)

{-| Add one to the counter. -}
increment : Int -> Int
increment n =
    n + step

{-| The step size used by `increment`. -}
step : Int
step =
    1
```
