# IPE-N0002: cannot find this type in scope

You wrote a type name — in a type annotation or a type declaration — that does not refer to any type I know about. I checked the built-in types and the types declared in this module, and nothing matched the name you used.

Usually this is a small spelling slip, or a type that simply has not been declared yet. If your name is close to a type I do recognise, I will suggest it.

Here the type name in an annotation is misspelled:

```ipe ipe:error
count : Itn
count = 0
```

I do not have a type called `Itn`. You meant `Int`:

```ipe
count : Int
count = 0
```

If you are referring to your own type, make sure it is declared before you rely on it. Declare the union, then annotate with it:

```ipe
type Color
    = Red
    | Green
    | Blue

favourite : Color
favourite = Green
```
