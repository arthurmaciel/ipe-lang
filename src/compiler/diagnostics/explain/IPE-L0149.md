# IPE-L0149: a JS port boundary value is not emittable yet (raw port transport not shipped)

A **port** is the raw typed channel between an Ipê app and its page JavaScript:
`Js.send` carries a value out, `Js.subscribe` receives one in. The **type** side
of a port is now checked: the value you send, or the value your decoder produces,
is verified to be a plain, closed, sealable value (see IPE-L0148 for what that
means).

```ipe ipe:skip
ping : Cmd Msg
ping =
    Js.send { kind = "ping", at = 0 }
```

What is not built yet is the **transport** — the machinery that actually moves a
port value across the seam: the per-target lowering (a network stream when the app
runs on the server, an in-process hand-off when it runs in the browser as WASM)
and the small `ipe.send` / `ipe.onReceive` JavaScript glue that the page calls.
Until that ships, a program that *builds* a port cannot be compiled all the way to
a running program.

The compiler stops here, cleanly, rather than emitting a program whose port has no
working channel. This is deliberate: no boundary value ever reaches code
generation without its typed transport in place, so a half-wired port can never
slip through and cross the seam untyped.

## How to fix

Until the port transport ships, reach the page through a surface that is already
built: a typed custom-element widget (`Ui.widget`) for in-view JavaScript, or an
ordinary typed event handler in your `view`. Keep your `Js.send` / `Js.subscribe`
code — it is already type-checked and seal-checked, and becomes buildable when the
transport lands, with the JSON encode/decode glue generated for you automatically.

## Glossary

- **transport** — the mechanism that carries a boundary value across the
  Ipê↔JavaScript seam. The typed contract is fixed; the transport is the code that
  realises it, and it differs per target (server stream vs in-browser hand-off)
  while the developer surface stays identical.
- **port** — the raw typed channel for imperative effects and out-of-band data,
  as opposed to the in-view custom-element boundary.
- **fail closed** — when something is not yet possible, refuse it rather than emit
  a broken program. Here: refuse to build a port whose transport is not shipped.
