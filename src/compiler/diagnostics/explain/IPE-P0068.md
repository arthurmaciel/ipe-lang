# IPE-P0068: type annotation has no matching value binding

A standalone `name : Type` annotation was written, but no `name = …`
definition follows it in the module. An annotation is only a *promise* about a
value's type; on its own it binds nothing. Rather than quietly discard the type
you wrote, the compiler rejects the orphan so the mismatch cannot hide.

The usual cause is a typo: the annotation and the definition spell the name
differently.

```ipe ipe:error
module Counter exposing (increment)

incrementt : Int -> Int
increment n =
    n + 1
```

Here `incrementt` (the annotation) and `increment` (the definition) differ by
one letter, so the annotation attaches to nothing.

## To fix

Make the annotation's name match its definition exactly:

```ipe
module Counter exposing (increment)

increment : Int -> Int
increment n =
    n + 1
```

If the annotation was left over from a deleted definition, remove it:

```ipe
module Counter exposing (increment)

increment n =
    n + 1
```
