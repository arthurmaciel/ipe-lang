# SKY-L0104: only Task () is supported yet

You wrote a `Task` type that carries a result — something like
`Task Int` or `Task String`. Sky understands the shape, but this version
only supports `Task ()`: a task that runs an effect and returns nothing
useful. Tasks that produce a value aren't compiled yet.

This is a feature still on the way, not an error in your code. For now,
treat a task as "do this effect" rather than "do this and give me back a
value", and keep the type as `Task ()`.

`[feature: task-results]`

A task returning an `Int` hits this limit:

```sky
fetchCount : Task Int
fetchCount =
    countRows
```

So does any other result type:

```sky
readName : Task String
readName =
    promptForName
```

A task that only performs an effect is fine — give it the `Task ()`
type:

```sky
main : Task ()
main =
    Log.println "starting up"
```

This is a current limitation, not a wrong move on your part. If you
need result-bearing tasks soon, let us know at
https://codeberg.org/sky-lang/sky-rust/issues.
