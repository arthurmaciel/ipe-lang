# IPE-N0003: cannot find this constructor

You used a constructor — in a pattern or in an expression — that is not defined anywhere in scope. Constructors are the tags you list when you declare a `type`, like `Red`, `Just`, or `Ok`. I could not find one with the name you wrote.

This is most often a typo, or a constructor from a type you have not declared (or not imported) yet. If your name is close to a constructor I do know, I will suggest it. Remember that constructor names always start with an uppercase letter — a lowercase name is treated as a variable, not a constructor.

Here a constructor is misspelled in an expression:

```ipe ipe:error
type Color
    = Red
    | Green
    | Blue

pick : Color
pick = Gren
```

I do not have a constructor `Gren`. You meant `Green`:

```ipe
type Color
    = Red
    | Green
    | Blue

pick : Color
pick = Green
```

The same applies inside a `case` pattern — every pattern tag must be a constructor that exists on the type you are matching:

```ipe
type Color
    = Red
    | Green
    | Blue

name : Color -> String
name color =
    case color of
        Red ->
            "red"

        Green ->
            "green"

        Blue ->
            "blue"
```
