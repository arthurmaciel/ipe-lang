# IPE-L0101: operator not supported yet

You used a binary operator that Ipe can parse but cannot compile yet.
Right now only `+` and `-` are wired all the way through to the backend.
Operators like `*`, `/`, `==`, and `++` are recognised by the grammar,
but lowering them isn't implemented in this version.

This is a gap in the compiler, not an error in your thinking — the
operator means exactly what you'd expect, it just doesn't have a code
path yet. The span points at the operator that stopped me.

`[feature: binops]`

Multiplication isn't available yet:

```ipe ipe:skip
area : Int
area =
    width * height
```

Neither is equality or string concatenation:

```ipe ipe:skip
greet : String
greet =
    "hello, " ++ name
```

For now, stick to addition and subtraction, which are fully supported:

```ipe ipe:skip
shifted : Int
shifted =
    base + offset - 1
```

This is a current limitation, not a mistake you made. If you need a
particular operator soon, let us know at
https://github.com/arthurmaciel/ipe-lang/issues and we'll bump it up the
list.
