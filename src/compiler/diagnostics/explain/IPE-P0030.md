# IPE-P0030: missing '=' in definition

I started reading a definition — a name, maybe followed by some
parameters — and then expected an `=` to introduce its body, but the
`=` wasn't there. Without it I can't tell where the thing you're
naming stops and its value begins.

In Ipe every definition has the form `name = value` (or `name arg1 arg2
= value` for a function). If the `=` is missing, mistyped, or pushed
onto the wrong line, I reach this point and stop. Check the line at the
caret: the left side names something, and an `=` must come next.

A binding with no `=` leaves me waiting for one:

```ipe ipe:error
greeting "hello"
```

Insert the `=` between the name and its value:

```ipe
greeting =
    "hello"
```

A function works the same way — parameters come before the `=`, the
body after it:

```ipe
double n =
    n * 2
```
