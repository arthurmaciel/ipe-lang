# IPE-L0134: a function-carrying collection element is not comparable

A function value can now be **stored** in a `List` element or a `Dict` value: it
is carried on a shared, reference-counted `Arc<dyn Fn>` handle, which is
`Clone`, so a `List (Int -> Int)` or a `Dict String (Event -> Msg)` can be built,
mapped, folded, filtered, and forwarded freely.

What a function value is **not** is comparable. An `Arc<dyn Fn>` implements
neither equality (`PartialEq`) nor ordering (`PartialOrd`/`Ord`) — there is no
meaningful, decidable "are these two functions equal / which is smaller"
operation. So a collection operation that compares or orders its element has no
sound representation over a function element, and is rejected here at lowering
rather than emitting Rust that would not compile.

The rejected operations are the equality- and ordering-requiring collection
kernels:

- `List.member` (needs `==` on the element)
- `List.unique` (needs `==` to deduplicate)
- `List.sort`, `List.maximum`, `List.minimum` (need an ordering on the element)

Every other collection operation — `List.map`, `List.filter`, `List.foldl`,
`List.foldr`, `List.concatMap`, `Dict.map`, and the rest of the
map/fold/structural family — only moves or clones its element, so it works over a
function-carrying collection.

## Compare on a non-function key instead

If you need membership or ordering, key on a comparable value and keep the
function in the value position:

```ipe
handlers : Dict String (Event -> Msg)
handlers =
    Dict.insert "click" onClick Dict.empty

hasClick : Bool
hasClick =
    Dict.member "click" handlers
```

`Dict.member` compares the **key** (`String`), which is comparable; the value is
a function, which is stored, not compared.

## Store a tag alongside the function

When you have a list of functions and need to find or dedupe them, pair each with
a comparable tag and operate on the tag:

```ipe
type Step
    = Step String (Int -> Int)

run : Step -> Int -> Int
run (Step _ f) n =
    f n
```

Sort, dedupe, or search on the `String` tag; apply the function by projecting it
out of the pair.
