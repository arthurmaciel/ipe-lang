# IPE-P0013: integer literal out of range

I read an integer literal that is too large to fit in Ipe's `Int`. The
digits are all valid, but the value they spell is bigger than the
biggest whole number Ipe can hold, so I can't turn it into a real
number.

`Int` in Ipe is a fixed-width signed integer. Once a literal exceeds
that range there's no way to store it faithfully, and silently
wrapping it around to a wrong value would be worse than stopping — so I
stop here. The fix is to use a value that fits, or to reach for a type
built for larger or fractional numbers.

A literal past the limit lands here:

```ipe ipe:error
huge =
    999999999999999999999999999999
```

If the magnitude isn't essential, use a value within range:

```ipe
big =
    1000000000
```

If you really need arbitrary-size or fractional magnitudes, model the
quantity with a wider numeric type rather than a bare `Int` literal:

```ipe
price : Float
price =
    9.99
```
