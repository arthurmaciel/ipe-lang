# IPE-P0015: malformed character literal

I started reading a character literal at an opening `'` but it was not
a single character closed by a matching `'`. A Ipe character literal
holds exactly one character (or one escape sequence such as `\n`)
between two single quotes — for example `'a'` or `'\n'`. An empty
`''`, a run of several characters, or a missing closing quote is not a
valid character literal.

If you meant a piece of text rather than one character, use a string
literal with double quotes instead. If you meant a single character,
keep exactly one between the quotes and close it.

An empty character literal lands here:

```ipe ipe:error
nothing =
    ''
```

More than one character does not fit in a `Char` — use a string:

```ipe
word =
    "hi"
```

A single character, properly closed, is valid:

```ipe
initial =
    'A'
```
