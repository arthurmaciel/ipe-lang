# IPE-N0043: a bare `let _ =` binds nothing and isn't allowed

`_` is the wildcard pattern. Inside a larger pattern it names a value you want to
**ignore** — the second half of a pair, an argument you never read:

```ipe
let (a, _) = (1, 2)   -- keep `a`, ignore the rest
in
a
```

That is fine. What is *not* fine is making `_` the **whole** of a `let` binding:

```ipe
main : Task Error ()
main =
    let _ = Io.println "step one"
    in
    Io.println "step two"
```

Here the pattern binds nothing at all, so the value on the right is computed only
to be thrown away. That is almost never what you mean — and for an effect like
`Io.println` it hides *when* the effect runs, so Ipê rejects it.

## To run an effect and ignore its result

Sequence it. `Task.andThen` runs the first task, ignores its result with a
`\_ -> …` continuation, and hands you the next:

```ipe
main : Task Error ()
main =
    Io.println "step one"
        |> Task.andThen (\_ -> Io.println "step two")
```

A `do` block reads the same way and is often clearer for several steps:

```ipe
main : Task Error ()
main =
    do
        Io.println "step one"
        Io.println "step two"
```

Every bare line inside `do` is exactly "run this effect, ignore its result, keep
going" — the pattern this binding was reaching for, spelled the supported way.

## To drop a pure value

If the right-hand side has no effect, the binding does nothing — just delete it.
If you wrote it to silence an "unused" note, bind a real name and use it, or
compute the value only where you actually need it.

## Why the whole-binding case is special

A `_` *inside* a pattern still works everywhere:

```ipe
increment : (Int, Int) -> Int
increment (a, _) =
    a + 1

describe : Maybe Int -> String
describe m =
    case m of
        Just _ -> "something"
        Nothing -> "nothing"

apply : (Int -> Int) -> Int
apply f =
    (\_ -> f 1) "ignored"
```

Only a `let` (or `def`) whose **entire** bound pattern is a bare `_` is rejected
— because it binds nothing and quietly discards its right-hand side.
