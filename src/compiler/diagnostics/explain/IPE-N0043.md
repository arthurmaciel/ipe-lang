# IPE-N0043: a config binding is declared but never threaded into an app entry

Ipê lets an app gather its cross-cutting wiring — how it binds its host, what it logs, its database URL, its CSRF and session policy, its secrets — into one top-level binding named `config`, a plain `List (Setting shape)`:

```ipe ipe:skip
module Main exposing (main)

import Ipe.App as App
import Ipe.Tea.Web as Web

config : List (Setting Web)
config =
    [ Host.bind Host.loopback
    , Web.csrf Web.strict
    , Db.url (App.fromEnv "DATABASE_URL")
    ]

main =
    Web.app
        { init = init, update = update, view = view
        , subscriptions = subscriptions, routes = routes, notFound = NotFound
        }
```

When a module has both a `config` binding and a `Web.app` entry, the compiler threads `config` into the entry for you — it behaves exactly as if you had written `Web.appWith config { … }`. That threading is the *only* thing that installs the settings.

So a `config` binding that is **never** passed to an app entry is inert: the runtime never reads it, and every setting it lists is silently dropped — a host bind that never takes effect, a CSRF posture that is never enforced, a secret that is never loaded. That silent drop is a security footgun, so it is rejected here, mirroring the discarded-`Task` lint (IPE-L0141): a value whose whole purpose is a runtime effect must reach the site that consumes it.

This trips the gate — a `config` binding with no Web app entry to thread it into:

```ipe ipe:skip
module Main exposing (main)

import Ipe.App as App
import Ipe.Io as Io

config : List (Setting Web)
config =
    [ Db.url (App.fromEnv "DATABASE_URL") ]

main : Task Error ()
main =
    Io.println "the config above is never installed"
```

To fix it, thread the settings into an app entry — either implicitly by giving the module a `Web.app` entry (the sibling `config` binding is threaded automatically), or explicitly with `Web.appWith`:

```ipe ipe:skip
module Main exposing (main)

import Ipe.App as App
import Ipe.Tea.Web as Web

config : List (Setting Web)
config =
    [ Db.url (App.fromEnv "DATABASE_URL") ]

main =
    Web.appWith config
        { init = init, update = update, view = view
        , subscriptions = subscriptions, routes = routes, notFound = NotFound
        }
```

If the `config` binding is genuinely unused, delete it — a binding that installs nothing has no reason to exist.
