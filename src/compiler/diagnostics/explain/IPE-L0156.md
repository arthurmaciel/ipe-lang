# IPE-L0156: a literal route pattern or server route path is malformed

A `Web.route` pattern and the path of a `Server.*` route (`Server.get`,
`Server.post`, `Server.api`, `Server.static`, `Server.mountApp`, …) follow one
grammar, the same one the runtime checks before it serves a request:

- A parameter segment is `:name` (or `*name` for a server catch-all). The name
  is a letter or `_` followed by letters, digits, or `_`:
  `[A-Za-z_][A-Za-z0-9_]*`.
- Every parameter in one path has a distinct name.
- In a `Web.route` pattern, a literal segment is strictly percent-decodable:
  each `%` starts an escape of two hex digits, and the decoded bytes are valid
  UTF-8.

When the path is a string literal, `ipe` refuses a path that breaks the grammar
at compile time, so the program never starts with a route table the runtime
would turn back.

A parameter name must be an identifier:

```ipe ipe:error
-- ✘ `-` is not allowed in a parameter name.
routes = [ route "/posts/:post-id" PostPage, ... ]

-- ✔
routes = [ route "/posts/:post_id" PostPage, ... ]
```

A parameter needs a name, and each name appears once per path:

```ipe ipe:error
-- ✘ No name after `:`.
routes = [ route "/posts/:" PostPage, ... ]

-- ✘ `id` names two segments.
routes = [ route "/users/:id/posts/:id" UserPostPage, ... ]

-- ✔
routes = [ route "/users/:user_id/posts/:post_id" UserPostPage, ... ]
```

A `%` in a `Web.route` literal segment starts a two-hex-digit escape of UTF-8
bytes:

```ipe ipe:error
-- ✘ `%zz` is not an escape.
routes = [ route "/files/100%zz" FilesPage, ... ]

-- ✔ `%25` is a literal percent sign.
routes = [ route "/files/100%25" FilesPage, ... ]
```
