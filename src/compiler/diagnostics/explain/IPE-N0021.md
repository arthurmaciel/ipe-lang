# IPE-N0021: import cycle

Two or more modules import each other, forming a cycle. Ipe modules must form a directed acyclic graph so that each module can be compiled using only already-compiled dependencies.

A direct cycle between two modules:

```ipe
-- src/A.ipe
module A exposing (f)
import B
f = B.g
```

```ipe
-- src/B.ipe
module B exposing (g)
import A
g = A.f
```

Module `A` imports `B`, and `B` imports `A`. This cycle makes it impossible to determine which module to resolve first. The error message lists the cycle path: `A → B → A`.

A longer cycle:

```ipe
-- src/Models.ipe
module Models exposing (User)
import Persistence
```

```ipe
-- src/Persistence.ipe
module Persistence exposing (save)
import Validation
```

```ipe
-- src/Validation.ipe
module Validation exposing (validate)
import Models
```

The path is `Models → Persistence → Validation → Models`.

To break the cycle, extract the shared types into a third module that none of the cyclic modules depends on:

```ipe
-- src/Types.ipe
module Types exposing (User)
type User = User { name : String, age : Int }
```

Then both `Models` and `Validation` import `Types` instead of each other.
