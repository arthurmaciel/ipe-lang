# IPE-P0067: exported binding has no doc-string

**This is a warning, not an error — the program still compiles and runs.**
**This lint is opt-in and is off by default.** Enable it with `--lint missing-docs`.

An exported binding — one that appears in the module's `exposing (…)` clause —
has no `{-| … -}` doc-comment above it. Callers of your module cannot read
documentation for this symbol in generated docs or editor tooling.

```ipe ipe:error
module Maths exposing (square, cube)

-- No doc-string here → IPE-P0067 when --lint missing-docs is on.
square : Int -> Int
square n =
    n * n

{-| Raise `n` to the third power. -}
cube : Int -> Int
cube n =
    n * n * n
```

## To fix

Add a `{-| … -}` doc-comment immediately above the binding, with no blank line
between the comment and the declaration:

```ipe
module Maths exposing (square, cube)

{-| Return `n` squared. -}
square : Int -> Int
square n =
    n * n

{-| Raise `n` to the third power. -}
cube : Int -> Int
cube n =
    n * n * n
```

## Doc-string syntax

A doc-comment starts with `{-|` (pipe immediately after the dash) and ends with
`-}`. Ordinary block comments `{- … -}` are never doc-strings; they continue to
be discarded by the compiler.

````ipe
{-| A doc-string for `greet`.

    Example:

    ```ipe
    greet "world"  -- "Hello, world!"
    ```
-}
greet : String -> String
greet name =
    "Hello, " ++ name ++ "!"
````

## Opting in

This lint is disabled by default to avoid noise on in-progress code. Enable it
for a module or project when you want to enforce complete public documentation.
