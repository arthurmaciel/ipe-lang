# IPE-P0061: malformed let expression

I was reading a `let … in` expression and its shape isn't right. A
`let` introduces one or more local bindings — each a lowercase name, an
`=`, and the value it stands for — then the keyword `in` and the
expression those names are used in.

Something in that structure is missing here: perhaps there are no
bindings before `in`, a binding name isn't a lowercase identifier, a
binding is missing its `=`, or the `in` keyword itself is absent. When
you write several bindings, line them up at the same column so I can
tell where one ends and the next begins.

A `let` with no bindings has nothing to introduce:

```ipe ipe:error
total =
    let in 0
```

Give it at least one binding — a name, `=`, and a value:

```ipe
total =
    let
        x = 2
    in
    x + x
```

Several bindings line up at the same column; a later one may use an
earlier one:

```ipe
area =
    let
        width = 3
        height = width + 1
    in
    width * height
```

Each binding is a simple value (`name = expr`). A binding that takes
parameters (`let f x = …`) is not supported yet — lift it to a
top-level function instead.
