# IPE-N0004: unknown module or import

You wrote a qualified name like `Qual.something`, but the part before the dot — the qualifier — does not name any module or import alias that is in scope here. I checked your imports and the built-in kernel modules, and `Qual` matched none of them.

This usually means the module name is misspelled, or you forgot to import it (or to give it the alias you are using). If the qualifier is close to one I recognise, I will suggest it.

Here a kernel module name is misspelled:

```ipe
main : Task ()
main =
    Logg.println "hi"
```

There is no module `Logg`. You meant `Log`:

```ipe
main : Task ()
main =
    Io.println "hi"
```

If you are using an alias, make sure the import that introduces it is present. Bring the module in, then qualify with the alias you chose:

```ipe
import Ipe.Core.String as Str

shout : String -> String
shout text =
    Str.toUpper text
```
