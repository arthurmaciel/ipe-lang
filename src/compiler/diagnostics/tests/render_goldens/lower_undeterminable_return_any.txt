  = note: a wildcard `any` stands for one concrete type the compiler must be able to work out. In the return type it can only be worked out from the body (make the body produce a concrete value) or from a parameter that also uses it (so the caller's argument fixes it). Here it is neither, so no caller could ever pin it. Annotate a concrete return type, return a concrete value from the body, or add a parameter that carries the same `any`. To keep it genuinely polymorphic instead, use a named type variable such as `a`.
