  = note: a `Task` runs its effect only through `Task.run`, or by being sequenced inside a function whose own return type is a `Task`. Discarding it with `let _ = <task>` in a non-`Task` function would run it through a hidden `Task.run`. Give the enclosing function a `Task e ()` return type and let its result be the sequenced tasks, or run the effect explicitly with `Task.run`.
